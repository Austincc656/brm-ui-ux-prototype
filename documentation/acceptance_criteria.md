# Acceptance Criteria – BRM Features

## 1. Create Requirement Form
- [ ] User can enter title, description, category, priority
- [ ] Form cannot be submitted with empty title
- [ ] System stores the requirement in the database
- [ ] A confirmation message appears after submission

## 2. Dashboard
- [ ] Dashboard shows total requirements
- [ ] KPI cards display counts (Approved, Pending, In Progress)
- [ ] Dashboard updates automatically when data changes
- [ ] Dashboard loads in under 2 seconds

## 3. Sidebar Navigation
- [ ] Sidebar contains BRM logo + 5 navigation items
- [ ] Active page is highlighted
- [ ] Sidebar remains fixed on all screens

## 4. Analytics Page
- [ ] Requirements status chart loads successfully
- [ ] User can filter by date or category
- [ ] At least one KPI is visible

## 5. Mobile Layout
- [ ] Sidebar collapses into hamburger menu
- [ ] Dashboard cards stack vertically
- [ ] Input forms remain usable on small screens
