# Functional Requirements – BRM

## FR1: Sidebar Navigation
- The system must provide sidebar navigation with 5 menu items.
- The active item must be highlighted.

## FR2: Requirement Creation
- Users must be able to create new requirements.
- The system must validate required fields.
- Requirements must be saved and viewable immediately.

## FR3: Dashboard KPIs
- The system must display:
  - Total requirements
  - Approved requirements
  - Pending requirements
  - In-Progress requirements

## FR4: Requirement List View
- Users must see all requirements in a searchable list.
- List must support filtering by status and category.

## FR5: Analytics View
- The system must show charts summarizing requirement status.
- Charts must update based on filters.

## FR6: Stakeholder Management
- User must be able to add stakeholders with Name, Role, Contact.

## FR7: Mobile Adaptation
- System must be usable on a 375px-wide screen.
