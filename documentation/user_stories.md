# User Stories – Business Requirement Manager (BRM)

## 1. Requirement Creation
As a Business Analyst,
I want to create new requirements using a simple form,
so that I can document project needs clearly.

## 2. Requirement Categorization
As a Product Owner,
I want to assign categories and priorities,
so I can organize requirements effectively.

## 3. Status Update
As a Project Manager,
I want to update requirement status (Draft → Approved),
so I can track project progress.

## 4. Dashboard Visibility
As an executive or stakeholder,
I want to see KPI summaries on the dashboard,
so I can quickly understand the project status.

## 5. Requirement Search
As a BA,
I want a search bar to find requirements quickly,
so I can avoid manual scanning through long lists.

## 6. Analytics Insights
As a manager,
I want analytics charts for requirement distribution,
so I can identify progress and bottlenecks.

## 7. Mobile View
As a team member,
I want to access requirements on my phone,
so I can review or update items on the go.

## 8. Stakeholder Management
As a BA,
I want to add and track stakeholders,
so I know who is responsible or impacted.
