# brm-ui-ux-prototype
A Business Requirement Management (BRM) dashboard prototype designed in Figma. This project demonstrates core BA skills including UI design, requirement structuring, process logic, and dashboard layout planning for a modern web application.
🚀 Overview

This repository contains the UI/UX prototype for a Business Requirement Management (BRM) application, designed entirely in Figma.
The project demonstrates my ability to translate business needs into structured, intuitive, and user-centered digital interfaces — an essential skill for a Business Analyst.

The prototype includes:

Low-fidelity wireframes

High-fidelity UI screens

Dashboard layout

Sidebar navigation

Header bar

Requirement input form

Analytics overview

Mobile UI design

This project reflects real BA workflows such as requirement scoping, interface planning, user flow mapping, and dashboard structuring.

🎯 Purpose of the Project

The goal of this project is to:

Practice transforming business logic into UI/UX design

Demonstrate BA skills through interface structure and feature definition

Build a portfolio-ready, modern dashboard application

Showcase familiarity with Figma, layout grids, components, and responsive thinking

Present a professional example of how I would contribute to product development teams
